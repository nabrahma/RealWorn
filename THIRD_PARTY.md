RealWorn is GPL-3.0-or-later. The projects below were studied for ideas. Any function adapted from
one of them keeps its licence header and a comment naming the source file and commit.

| Project | Licence | Commit studied | Ideas used | Code copied |
| --- | --- | --- | --- | --- |
| [Ucupaint](https://github.com/ucupumar/ucupaint) | GPL-3.0 | `0bed732` | Canvas switching and Image Editor restore, brush asset activation, save-time packing, bake setting restore | None |
| [Paint System](https://github.com/natapol2547/paintsystem) | GPL-3.0-or-later | `8991037` | Declarative node rebuild, save fallback (pack when save fails), scoped keymaps | None |

`realworn/builders/` and released under CC0.
